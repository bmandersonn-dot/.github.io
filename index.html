Ascension Ministry Planner

Ascension Ministry Planner is a small planning tool used by a church worker at Ascension Lutheran Church to organize ministry events, daily tasks, schedules, budgets and notes. It runs on the user's own computer.

What it does with Google

  • Google Calendar: with the user's permission, it creates and updates events in a calendar of its own so the user's schedule is also visible on their phone.
  • Google Drive (hidden app-data folder only): it keeps a private copy of the planner's data so the same planner can be used on more than one computer. It does not read or change any other files in Google Drive.

This app is for personal use by its owner. It is not offered to the general public.
